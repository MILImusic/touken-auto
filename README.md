# touken-auto

刀剣乱舞 (Touken Ranbu) 日服自动化脚本。仅适用于 **macOS + 网页版 (DMM Game Player)**。自动完成日常任务、地下城、出击循环、远征管理、习合刀解等。

## 功能

### 出击循环

所有出击模式默认使用**部队3**，自动处理远征回收、重伤治疗、气力恢复。战斗时自动根据敌方阵型选择克制阵型。

| 模式 | 说明 | 备注 |
|------|------|------|
| 循环 4-4 | 主刷委托符（依赖札） | 每 15 次检查依赖札获取量，动态调整休息时长 |
| 循环 4-3 | 主刷冷却材 | |
| 循环 4-2 | 主刷砥石 | |
| 循环 5-2 | 主刷木炭 | |
| 循环 6-1 | 主刷砥石，高速枪图 | 推荐极短刀速度 > 150，马匹效果减半 |
| 循环 7-3 | 高难图，跳过最终战 | **不打最后一个节点**，减少刀装消耗 |
| 循环 7-4 | 高难图 | |

### 地下城

| 模式 | 说明 |
|------|------|
| 爬楼地下城 | 从指定层爬到目标层（默认 90 层），每 10 层自动回城处理气力 |
| 循环地下城 | 在同一层无限循环刷（用于刷特定楼层掉落） |

### 异去

| 模式 | 说明 |
|------|------|
| 异去（日常） | 每日最多 3 次，含剧情对话自动跳过 |
| 循环异去 | 无限循环直到次数耗尽（适用于购买了额外次数的情况） |

### 日常任务

一键完成所有日常：重伤治疗 → 远征回收/发出 → 演练（5 场） → 异去（3 次）。

### 习合 / 刀解 / 综合管理

| 模式 | 说明 |
|------|------|
| 习合 | 从受取箱领取短刀，自动习合 |
| 刀解 | 从受取箱领取非短刀，自动刀解释放刀位 |
| 综合管理 | 习合 + 刀解一体化，刀位满时自动腾位 |

**习合逻辑：**
- **保护刀**：自动喂到乱舞 Lv.10
- **未保护短刀**：互相喂到乱舞 Lv.7（搓糖）
- **極化关联**：截止到小鹿大太刀之前的極化刀，自动关联未極化版本（sword_id - 1）作为素材，防止漏喂和错喂
- 每次习合最多 30 把素材，自动分批

**刀解逻辑：**
- 保护刀不会被刀解
- 不会解锁任何保护刀
- 在队 / 内番中的刀不会被刀解
- **新刀保留**：仓库中没有保护版本的新刀自动留一把开图鉴
- 如果同 sword_id 有保护刀且乱舞等级未满，优先喂给保护刀再刀解剩余

### 气力恢复

指定队伍全员逐把跑 1-1 补满气力至 100。过疲劳（气力 = 0）时自动停止脚本并发送 Telegram 告警。

### 安全机制

- **重伤检测**：覆盖所有出战单位（不只是队长），HP <= 30% 自动送修
- **队伍完整性验证**：治疗前后五层校验，缺人自动补回 + 重装刀装
- **气力监控**：3 把以上低于 70 或任意一把低于 40 时触发恢复，过疲劳自动停止
- **请求节流**：非战斗请求 短随机延迟，战斗请求 长随机延迟，每 10-20 轮暂停休息
- **异常通知**：脚本报错、气力异常、新刀锻造均通过 Telegram 推送

## 环境要求

- macOS（自动登录依赖 Chrome + opencv 截图）
- Python 3.11+
- Google Chrome（需要一个已登录 DMM 的 Profile）

## 安装

```bash
git clone https://github.com/MILImusic/touken-auto.git
cd touken-auto
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

自动登录还需要额外依赖：

```bash
pip install opencv-python pyautogui
playwright install chromium
```

## 配置

复制 `.env.example` 为 `.env` 并填写：

```bash
cp .env.example .env
```

| 变量 | 必填 | 说明 |
|------|------|------|
| `UID` | 是 | 游戏 UID |
| `SERVER` | 是 | 服务器标识（如 `w021`） |
| `SWORD` | 否 | sword cookie，手动输入模式用 |
| `TELEGRAM_BOT_TOKEN` | 否 | Telegram Bot Token，用于告警通知 |
| `TELEGRAM_CHAT_ID` | 否 | Telegram Chat ID |
| `HTTP_PROXY` | 否 | HTTP 代理地址（如 `http://127.0.0.1:7897`） |

### 获取凭证

**自动登录（推荐）**：脚本启动后选择选项 1，通过 opencv 截图匹配 + pyautogui 自动点击完成登录并提取 token。限定 **Google Chrome + Google 账号登录 DMM**，需要在 Chrome 中预先登录对应的 Google 账号。

**手动输入**：在 Chrome DevTools → Application → Cookies 中复制 `sword` 和 `fuel_csrf_token` 的值。

## 使用

```bash
source venv/bin/activate
python main.py
```

启动后选择运行模式即可。出击循环模式会自动处理远征、重伤治疗、气力恢复。

### 队伍编成要求

- **部队1**：白山吉光专属治疗队，只放白山一把刀，且白山必须是队伍中**速度最快**的（确保队长位）
- **部队3**：所有出击循环（4-2 / 4-3 / 4-4 / 5-2 / 6-1 / 7-3 / 7-4 / 地下城 / 异去）默认使用部队3
- **远征**默认配置：2队→2-4、3队→4-2、4队→5-1、5队→5-2，可通过 `.env` 的 `EXPEDITION_TARGETS` 修改（格式：`部队号:地图ID` 逗号分隔）

## 项目结构

```
api/
  client.py          # HTTP 客户端（Double Submit + CSRF 链式轮换）
  battle.py          # 战斗 + 气力恢复
  repair.py          # 重伤治疗（白山吉光专属队）
  sortie.py          # 出击循环（4-2 ~ 7-4）
  dungeon.py         # 地下城爬楼 / 单层循环
  parallel_past.py   # 异去
  expedition.py      # 远征收发
  practice.py        # 演练
  composition.py     # 习合
  dismantle.py       # 刀解
  sword_manager.py   # 综合管理（习合 + 刀解）
  fatigue_recovery.py # 气力恢复
  notify.py          # Telegram 通知
auth/
  auto_token.py      # Chrome 自动登录 + token 提取
  dmm_login.py       # Playwright 备用登录
```

## 历史教训

以下 bug 曾造成不可逆损失，已修复但值得记录：

1. **非队长重伤检测缺失**：异去模块只检测队长 HP，非队长刀剑重伤后继续出战导致碎刀。现已改为检测全队。

2. **单人出征触发封号**：队伍缺人时仍发送出征请求。现已加入队伍完整性验证，缺人时中止出击。

3. **请求频率过高**：无延迟连续请求会被服务器检测。现已加入随机延迟和定期休息。
